# AI アシスタントの会話をまたぐ記憶（設計・守りの規則）

2026-11-23 利用者「会話の永続記録は？有用なら採用して。設定で選べるように。情報の流出を懸念している。保護された会話や特許のアイデア関連の記憶は、インターネット検索を保護されていない会話には露呈できない」。

## 主要な AI の記憶との比較（既存の知識の範囲。外部へは取りに行っていない）

| | ChatGPT の Memory | Claude の memory | ローカルの OSS（mem0・Letta 等） | ControlDeck（本設計） |
|---|---|---|---|---|
| 作り方 | 会話から自動＋「覚えて」。参照する過去チャット履歴も使う | 会話の要約を定期的に作る・プロジェクト単位で分ける | LLM が会話から事実を抜き、ベクトル DB に入れる | 設定で 切／明示だけ／候補を承認／自動 |
| 使い方 | 毎回の文脈へ入れる。会話ごとに一時チャット（記憶なし）がある | 同じプロジェクトの会話へ入れる。切り替えあり | 検索して上位を入れる | 答えの段にだけ上位 5 件。会話ごとに切替 |
| 見る・消す | 一覧・個別削除・全消し | 一覧・編集・削除 | API で操作 | 一覧・編集・削除・全消し・会話と一緒に消す |
| 機密の区分 | 無い（プロジェクトの分離程度） | プロジェクトの分離 | 無い | **protected（秘密の会話・特許の流れ）を中心に据える** |

どれも「記憶を作る・使うモデル」が同じクラウド側で、機密の区分や検索への漏れを仕組みで断つ層は無い。ControlDeck は
(1) Web 検索・外部 LLM を使う会話があり、(2) 特許のアイデアを外へ出さない決定がある（own-ideas-local-llm-only）ので、
記憶の「作り」と「使い」の両方に、会話の種類に応じた堰を置く。

## 守りの規則（唯一の判定は `backend/app/memory/policy.py`）

1. **protected は秘密の会話の中でしか使わない。** 秘密の会話（`confidential_at`）・特許の流れ・利用者が「守る」にした記憶が protected。
   秘密でない会話には本文も要約も件数も出さない（`allowed_sensitivities` が normal だけを返す。`/memory/used` も秘密でない会話には protected を返さない）。
2. **外部の LLM（cloud:・ループバック以外）の会話には既定で入れない。** 設定「外部の AI の会話にも使う」を入れても normal だけ。判定は `offline.is_local_endpoint`（解決できなければ外部とみなす）。
3. **OpenCode にも既定で入れない。** 設定を入れても normal だけ。秘密の会話は元々 OpenCode へ流さない（二重）。
4. **記憶は答えを作る段にだけ入れる。** Web 検索の語を作る段（`_server_search` → research_intent）はその前に終わっていて記憶を渡さない（research_intent は触らず、呼ぶ側で入れない）。道具の引数にも渡さない。さらにモデルが記憶の言葉を道具の引数へ写したときは、道具の実行前に止める（`leaks_into_arguments`。会話に元からある言葉は許す）。
5. **作るのは手元の LLM だけ。** 取り出しは会話がクラウドでも `offline.local_target` のローカルで、`confidential_scope` の中で行う。ローカルが無ければ作らない。
6. **作った元の印は外せない。** 秘密の会話・特許から作った記憶は強制的に protected で、守りを外せない（`store.add` が強制。API は 409）。会話が途中で秘密になったら、その会話から作っていた記憶も protected へ寄せる。
7. 本文は `encrypt_text` で暗号化し、本体の DB と別の `data_dir/memory/memory.sqlite3` に置く（全文の索引は作らない）。監査（`memory.create`・`memory.delete`）に本文は残さない（種類・守られたか・文字数のみ）。秘密に見える文字列（鍵・パスワードらしきもの）は記憶にしない。

特許の流れ: 会話に `patent_case_id` を付けて送る、または特許分野のナレッジ検索の道具を使った回で、その会話に一方通行の印を立てる。以後その会話から作る記憶は protected。

## 設定（利用者ごと。設定 →「AI の記憶」）

- 記憶を使う（既定 入）。
- 作り方: 作らない／「覚えて」と言ったときだけ（既定）／自動で候補を出し承認したものだけ／自動で残す。
- 外部の AI の会話にも記憶を使う（既定 切）。OpenCode にも使う（既定 切）。
- 会話ごと（AI 設定の中）: この会話で記憶を使わない／この会話を記憶に残さない。会話の削除時に「この会話から作った記憶も消す」。
- 答えの下に「記憶を n 件使いました」（開くと一覧）。

## 選ばなかった案

- 外部の LLM に記憶の取り出しをさせる: 会話の全文が外へ出るので不可。
- 検索語の段へ記憶を渡して賢くする: 検索エンジンへ漏れるので不可（記憶の言葉の写しは道具の直前でも止める）。
- protected を秘密でない会話に「件数だけ」出す: 存在の漏れになるので不可。
