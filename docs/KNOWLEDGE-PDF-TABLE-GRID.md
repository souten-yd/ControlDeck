# PDF table grid reconstruction (Draft)

Stacked on #652. New pure Python helper accepts candidate cell rectangles and native word boxes in a common top-left point coordinate system. Validates rectangular grid topology, preserves logical row/column and explicit spans, raw word boxes and block/line/word evidence references. Missing/overlapping slots and invalid geometry rejected; crossing words marked unresolved; empty cell remains empty. Geometry is not inferred, visual reading order and headers are unverified, and the layout hash is not the original PDF hash. Candidate status is not proof of correctness. No measurement persistence, Cond binding, external access, new dependencies, PDF runtime hook, UI, API, DB, permission or default changes.
